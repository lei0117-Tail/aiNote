## 按主题理解整套文档

- 第一层是架构主线。
  先回答这个项目整体怎么分层、一次请求怎么流动、hooks/tools 怎么接在一起。

- 第二层是 Agent 体系。
  先看全量 agent，再区分核心执行型 agent 和辅助型 agent。

- 第三层是 Sisyphus 专题。
  重点看主力 agent 的 prompt 变体和动态构造机制。

- 第四层是调度与协作。
  重点看 `task`、后台任务、Team Mode 这三条执行基础设施。

- 第五层是规划链路。
  重点看 Prometheus 和 `.omo/plans` 这一类规划产物。
